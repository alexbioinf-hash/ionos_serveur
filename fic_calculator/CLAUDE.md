# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A single-file R Shiny web app that calculates the Fractional Inhibitory Concentration (FIC) index for antibiotic synergy testing from MIC (Minimum Inhibitory Concentration) values. Deployed at https://bigbiomed.shinyapps.io/fic_calculator/.

## Repository layout

- `fic_calculator/app.R` — the entire application (UI + server logic, Shiny single-file convention). This is the only source file.
- `fic_calculator/rsconnect/shinyapps.io/bigbiomed/fic_calculator.dcf` — deployment metadata for shinyapps.io (app ID, bundle ID, URL). Auto-generated by `rsconnect::deployApp()`; do not hand-edit.
- `fic_calculator_logo.jpg` / `fic_calculator_logo.pptx` / `fic_logo.png` — logo assets; the app itself pulls its header logo from a GitHub-hosted raw URL rather than a local file.

## Running the app

From an R session with working directory set to `fic_calculator/`:

```r
shiny::runApp()
```

Requires these packages to be installed: `shiny`, `ggplot2`, `rmarkdown`, `knitr`, `shinyjs`, `pdftools`, `DT`, `shinyWidgets`, `gridExtra`, `shinyFiles`, `fs`.

There is no build step, linter, or test suite in this repository.

## Deploying

Deployment is via `rsconnect::deployApp()` to the `bigbiomed` account on shinyapps.io. The `.dcf` file under `fic_calculator/rsconnect/` tracks the last deployment; shinyapps.io auth itself is configured outside this repo (in the local RStudio/R user config), not stored in the project.

## Architecture notes

- `calculate_fic()` is the single source of truth for the FIC formula and its interpretation thresholds (≤0.5 synergy, 0.5–1 additive, 1–4 indifference, >4 antagonism). Both the live result render and the downloadable report call this same function — keep them in sync if the formula changes.
- The UI embeds third-party tracking/ads (Google Analytics `gtag`, AdSense) directly as raw `HTML()`/`tags$script` blocks inside `ui`, gated by a custom consent popup that calls `gtag('consent', 'update', ...)`. When editing the UI, be careful not to break this consent-gating relationship.
- The downloadable report (`downloadHandler`) duplicates the calculation and formatting logic from the on-screen render rather than sharing a helper — this is the existing pattern, not an oversight to "fix" incidentally.
